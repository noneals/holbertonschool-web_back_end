# Python - Async Comprehension

This project contains exercises on async generators and async comprehensions in Python.

## Files

- **0-async_generator.py**: Async generator that yields random numbers
- **1-async_comprehension.py**: Async comprehension to collect values from async generator
- **2-measure_runtime.py**: Measure runtime of parallel async comprehensions

## Learning Objectives

- Understanding async generators
- Using async comprehensions
- Running async comprehensions in parallel
- Measuring runtime of parallel async operations

## Requirements

- Python 3.7+
- All files are executable
- All files use `#!/usr/bin/env python3` shebang
- Code follows pycodestyle guidelines
