# ES6 Basic

This project demonstrates the use of ECMAScript 6 (ES6) features in JavaScript. It covers various modern JavaScript concepts such as const/let variables, block scoping, arrow functions, default parameters, rest/spread operators, template literals, object shorthand, computed properties, method properties, for...of loops, and iterators.

## Requirements

- Node.js 20.x.x
- npm 9.x.x
- Ubuntu 20.04 LTS (or compatible environment)

## Installation

1. Install Node.js and npm as per the setup instructions in the project guidelines.
2. Clone or navigate to the project directory.
3. Run `npm install` to install dependencies (Jest, Babel, ESLint).

## Usage

Each task is implemented in its own file (e.g., `0-constants.js` for Task 0). To run a task, use the corresponding main file (e.g., `0-main.js`) with Babel:

```bash
npm run dev 0-main.js
```

### Tasks Overview

- **Task 0: Const or let?** - Demonstrates `const` and `let` usage.
- **Task 1: Block Scope** - Shows block-scoped variables with `let`.
- **Task 2: Arrow functions** - Converts to arrow syntax.
- **Task 3: Parameter defaults** - Uses default parameters.
- **Task 4: Rest parameter syntax** - Counts arguments with rest parameters.
- **Task 5: Spread syntax** - Concatenates arrays and strings.
- **Task 6: Template literals** - Substitutes variables in strings.
- **Task 7: Object property shorthand** - Simplifies object creation.
- **Task 8: Computed property names** - Uses dynamic keys.
- **Task 9: Method properties** - Defines methods in objects.
- **Task 10: For...of Loops** - Iterates over arrays.
- **Task 11: Iterator** - Creates employee objects.
- **Task 12: Report object** - Builds a report with methods.
